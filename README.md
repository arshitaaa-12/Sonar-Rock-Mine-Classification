# Sonar Rock vs Mine Classification

Machine learning project that classifies sonar signals as Rock or Mine
using Logistic Regression.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Model

Logistic Regression

## Evaluation

The model is evaluated using:
- Accuracy
- Confusion Matrix
- Precision
- Recall
- F1-score

## Dataset

The dataset contains sonar signal measurements used to classify
objects as Rock or Mine.
